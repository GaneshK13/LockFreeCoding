	Pointer chasing
		use software prefetch hints (to partially compensate)
		<xmmintrin.h>
		_mm_prefetch(reinterpret_cast<const char*>(current->next), _MM_HINT_T0);
		_MM_HINT_T0 -> L1, L2, L3
		_MM_HINT_T1 -> L1, L2
		_MM_HINT_NTA -> read once and never look at it again
	MESI hardware state machine
		every cache line in every core has to participate
		Modified
			single core access
			value different from main memory
		Exclusive
			single core access
			value same as main memory
			write required moving to Modified, without any inter-core communication
		Shared
			multi core access
			value same as main memory
			write on one core requires request for ownership and invalidation acknowledgement round trip from other cores (10-40 ns)
		Invalidate
			non-usable
